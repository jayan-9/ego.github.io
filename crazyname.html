3️⃣ Medium Name 📝

Crazy name banane ke liye hamesh medium name ka prayog karo – yani ki name na to jada lamba ho na to jada short. Short name jese sirf do word ka (EX, KO, LK) bohot hi short ho jayenge. Aur long name (MAXIMUMGAMER, CRAZYQUEENITE) bhi crazy name ke liye badhiya nahi rahenge.

Agar fir bhi long name use karne ho to:

  • Short font style ka use karo (ᴀ ʙ ᴄ, α в ¢, ᵃ ᵇ ᶜ) jo name ko lamba hote huye bhi short dikhayenge
  • Name ke bich me space rakho – MAXIMUMGAMER → Maxim Gamer – ye long name hote huye bhi perfect crazy name ban sakta hai
